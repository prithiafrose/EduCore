# 🎓 EduCore

EduCore is a modern full-stack University ERP (Enterprise Resource Planning) System designed to simplify academic and administrative operations.

It provides a centralized platform for students, teachers, and administrators to manage courses, attendance, assignments, results, timetables, notices, and fee payments.

---

## 🚀 Features

- Secure Authentication & Authorization
- Student Management
- Teacher Management
- Department Management
- Course Management
- Course Registration
- Timetable Management
- Attendance Management
- Assignment Management
- Result Management
- Notice Board
- Fee & Payment Management
- Dashboard for Students, Teachers, and Admin

---

## 🛠️ Tech Stack

### Frontend

### Backend
- Node.js

### Database
