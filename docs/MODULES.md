# EduCore System Modules

## 1. Authentication Module

Responsible for user authentication and authorization.

### Features

- Login
- Logout
- Change Password
- JWT Authentication
- Role-Based Authorization

---

## 2. User Management Module

Responsible for managing all users.

### Features

- Create User
- Update User
- Delete User
- View User
- Activate/Deactivate User

Supported Roles:

- Administrator
- Teacher
- Student

---

## 3. Department Management Module

Responsible for managing university departments.

### Features
