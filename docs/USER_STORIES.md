# User Stories

## Student

### Authentication
- As a student, I want to securely log in so that I can access my academic dashboard.
- As a student, I want to change my password so that I can keep my account secure.

### Academic
- As a student, I want to view my profile so that I can verify my personal and academic information.
- As a student, I want to register for courses so that I can enroll in the current semester.
- As a student, I want to drop a registered course before the deadline.
- As a student, I want to view my registered courses.

### Timetable
- As a student, I want to view today's class schedule.
- As a student, I want to know which teacher will take each class.
- As a student, I want to know the classroom for each class.
- As a student, I want to know whether a class is upcoming, ongoing, completed, or cancelled.

### Attendance
- As a student, I want to view my attendance history.
- As a student, I want to know my attendance percentage.

### Assignment
- As a student, I want to download assignments.
- As a student, I want to submit assignments before the deadline.
- As a student, I want to view assignment grades.

### Results
- As a student, I want to view my semester results.
- As a student, I want to view my CGPA.

### Notice
- As a student, I want to read university notices.

### Payment
- As a student, I want to pay my semester fees.
- As a student, I want to pay course registration fees.
- As a student, I want to download payment receipts.
- As a student, I want to view my payment history.

---

## Teacher

### Authentication
- As a teacher, I want to securely log in.

### Academic
- As a teacher, I want to view my assigned courses.
- As a teacher, I want to view my teaching schedule.

### Attendance
- As a teacher, I want to mark attendance.
- As a teacher, I want to update attendance if necessary.

### Assignment
- As a teacher, I want to create assignments.
- As a teacher, I want to upload assignment files.
- As a teacher, I want to grade student submissions.

### Results
- As a teacher, I want to publish marks.

### Class Management
- As a teacher, I want to cancel a class.
- As a teacher, I want to mark a class as completed.
- As a teacher, I want to upload course materials.

---

## Administrator

### User Management
- As an administrator, I want to manage students.
- As an administrator, I want to manage teachers.
- As an administrator, I want to manage administrators.

### Academic Management
- As an administrator, I want to manage departments.
- As an administrator, I want to manage programs.
- As an administrator, I want to manage semesters.
- As an administrator, I want to manage courses.
- As an administrator, I want to assign teachers to courses.

### Timetable
- As an administrator, I want to create class schedules.
- As an administrator, I want to update class schedules.

### Notice
- As an administrator, I want to publish notices.

### Finance
- As an administrator, I want to configure semester fees.
- As an administrator, I want to configure registration fees.
- As an administrator, I want to view payment reports.

### Dashboard
- As an administrator, I want to view system statistics.
